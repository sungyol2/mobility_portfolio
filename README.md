# Mobility, Planning & Data Visualization Portfolio

Selected work by Sun-Gyo Lee in transportation analytics, urban planning, geospatial analysis, and public-facing data communication.

**[View the portfolio](https://sungyol2.github.io/mobility_portfolio/)**

## Transit and mobility

- **[GTFS Visualization](https://sungyol2.github.io/GTFS/)** — Animated transit-network visualization using GTFS and employment data.
- **[Seattle Commuter OD Visualization](https://sungyol2.github.io/Commuting_Patterns/Seattle/)** — Interactive origin-destination map of regional commuting patterns and employment centers.
- **[EV Charging and Transportation Cost Burden](https://fdy6ae-sun0gyo-lee.shinyapps.io/City_Light_EV_Charging_Station/)** — R Shiny map comparing charging infrastructure with transportation cost burden.
- **[TriMet Transit-Oriented Development Regional Plan](https://trimet.org/tod/pdf/tod-regional-plan.pdf)** — Systemwide TOD framework and site-prioritization work for agency-owned properties.
- **[COVID-19 Impact on Local Travel Behavior](pandemic_impact_on_local_travel_behavior.pdf)** — Research on pandemic-era changes in mobility, mode choice, and transit use.

## Planning and communication

- **[City of Monroe 2044 Baseline Conditions](https://experience.arcgis.com/experience/019b6f45277f45d4a2444333ac17eea2#data_s=id%3AdataSource_17-9d8265dc842742609ea4ee692b7a5493%3A5114)** — Interactive planning dashboard covering land use, housing, growth, and community conditions.
- **[City of Kent 2044 Baseline Conditions](https://storymaps.arcgis.com/stories/ee9ddc4e2a9e4456b06b341ed7263003)** — Public-facing StoryMap communicating comprehensive-plan context and key issues.

## Walkability and streetscape

- **[Transit-informed Urban Network Analysis](cityseer/)** — Ballard case study using Cityseer and GTFS to examine how transit changes neighborhood accessibility.
- **[Active Streetscape Analysis](vital-streets/)** — Comparative analysis of street connectivity, frontage conditions, centrality, and public-facing activity in three downtowns.
- **[Seattle Activity Intensity Explorer](https://fdy6ae-sun0gyo-lee.shinyapps.io/Seattle_Activity_Intensity_Explorer/)** — R Shiny prototype mapping the relative concentration of public-facing amenities across Seattle.
